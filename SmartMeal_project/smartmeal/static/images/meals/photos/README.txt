Put your own meal photos in this folder to replace the illustrations.

Name each file after the meal id with two digits:
    meal_01.jpg   Greek Yogurt Protein Bowl
    meal_15.png   Salmon with Roasted Vegetables
    ...
Accepted formats: .jpg .jpeg .png .webp  (landscape 4:3, e.g. 800x600, works best)

The app checks this folder on every page: no restart and no database change needed.
Meal ids are listed in backend/meals/*.json. Use photos you are allowed to use
(your own pictures, or free-licence sites such as Unsplash or Pexels).
